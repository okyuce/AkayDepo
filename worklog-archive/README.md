# WORKLOG Arşivi

Eski `WORKLOG.md` kayıtları aya göre burada saklanır: `YYYY-MM.md` (örn. `2026-05.md`).

- Aktif `WORKLOG.md` yalnızca **son ~10 kaydı** tutar; daha eskiler buraya taşınır.
- Geçmiş bir iş/karar ararken **tüm arşivi context'e yükleme** — bu klasörde `grep` / `read` ile hedefli ara.
- Hangi ayların arşivlendiği her oturum başında (SessionStart hook) listelenir.
